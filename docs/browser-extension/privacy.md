# Saygo Browser 隐私说明

[扩展操作](README.md) · [商店材料](store.md)

政策内容最后更新于 2026-10-13；本页为中文整理版，适用于 Saygo Browser 扩展及本地桥。公开站点政策地址为 [saygo.work/privacy.html](https://saygo.work/privacy.html)，提交商店前应独立核验部署内容。

## 收集与使用范围

Saygo Browser 为用户授权的编程 Agent 提供本地桥。连接后，当前浏览器配置文件的网站标签页（含之后打开的页面）可供本地 Saygo 运行时操作。用户可在扩展弹窗主动释放连接。

连接期间可读取标签页 URL 和标题、截取图片并执行视觉输入；自动记录可控标签页的网络流量。内存中的网络记录可能包含请求/响应头、正文、WebSocket 消息和服务器发送事件，其中可能含个人资料、cookie、密码、访问令牌及其他敏感内容。浏览器限制页面不支持控制。请仅连接愿意向 Agent 提供访问权限的配置文件。

扩展与本机单独安装的 native messaging host 通信，不向开发者发送分析统计、不出售数据。本地运行时可能把观察、动作与报告写入磁盘。Agent 及其模型服务可能接收这些信息，处理方式由相应服务设置和隐私政策决定；本说明不承诺 Agent 会将全部资料留在本机。

## 保存与删除

断开连接终止扩展控制并清空活动网络记录，但不删除已返回 Agent 或已由 Saygo 保存的数据。删除扩展或注销 host 也保留本地任务记录。不再需要时可在 Saygo 数据目录删除相关记录；已交给 Agent/模型服务的数据按该服务的保留设置处理。

扩展日志只在内存保存，不设置正文长度或事件数量上限；内存用量随采集增长，用户可显式清空或停止采集。释放、断连或重启扩展时清空；本地运行记录保留至用户删除。不要把私人页面内容、密钥或截图附到公开问题中。

## 目的与有限使用

上述信息只用于用户指示的浏览器操作、观察和调试，不用于广告、转售、信用评估或借贷。开发者没有收集这些浏览器记录的服务端接口；除非用户主动为支持工作提供信息，开发者不会查阅它们。

Saygo Browser 对信息的使用和传输遵守 Chrome 网上应用店用户数据政策，包括有限使用要求。疑问可通过[项目问题入口](https://github.com/WilliamSkyWalker/saygo/issues)提出，勿包含私人资料。
