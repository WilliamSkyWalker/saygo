# 更新历史

本页记录产品行为变化、升级方式和验收边界；发布状态与构建成功分开记录。
浏览器扩展版本可独立于 Python 包版本。详细本轮验证见 [测试记录](testing/results.md)。

## 0.4.14 — 2026-10-12（发布中）

### 更新提醒修复

- 将检查版本、通知客户端、应用升级分开。pipx/package 安装即使 `automatic=false`，也会检查并提示更新。
- package 启动 MCP 后在后台查询公共 PyPI，选择有未撤回文件的更高稳定版本。
- `device_sessions` 返回可用版本、链接和 `pipx upgrade saygo-agent-control` 提示。缓存缺失、损坏、过期或包版本改变时会后台刷新；首次可返回 `checking: true`，后续调用读取结果。
- `saygo update --check` 和无参数 `saygo update` 真正执行检查。Saygo 不替 pipx 下载或切换运行时。
- 已升级的版本不再重复提醒。离线、缓存写入失败和线程启动失败不会阻断设备操作。
- 新 MCP 模块可补偿旧 package 启动器跳过检查的缺口；仍须先升级安装包并重启客户端，仓库源码修改不会自动修复已运行的 0.4.12。

### 需求、文档与测试

- 普通说明集中到 `docs/`；根目录保留 `agent.md`，客户端 Skill、命令模板和 QA 运行资源保留加载路径。
- 新增 186 条全项目需求基线，覆盖跨端控制、任务、工作流、GUI、QA、Probe、安装、更新与发布。
- 新增 633 条有独立自动化测试对应的 BDD 场景，以及 66 条跨模块/真实环境验收场景。
- 修正文档入口、包元数据、源码打包白名单及发布 notes 引用，CI 检查 BDD 与测试定义同步。
- 工作区中的桌面应用在研改动不包含在本次发布中；浏览器扩展保持 0.4.13。

### 升级与验证

```sh
pipx upgrade saygo-agent-control
```

升级后重启 Agent。已使用 package 环境的安装不需要重复 setup；旧复制运行时安装仍需一次 setup 迁移。

干净实现提交本地回归：879 条 Python 测试，871 通过、8 条环境条件跳过；4 个 Node 测试文件通过。
Linux 干净 wheel 安装、MCP 导入及重复 setup 通过。三平台 CI、PyPI 实际可见性和 GitHub 产物将在发布后分别核对；66 条环境场景不等于已完成真机验收。
