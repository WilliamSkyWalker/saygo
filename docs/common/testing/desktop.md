# 桌面回归测试范围

[测试目录](README.md) · [桌面应用](../desktop-app.md)

在仓库根目录并安装 desktop 依赖后执行：

```sh
python -m unittest discover -s tests/desktop_demo -v
```

桌面构建工作流在 Windows、macOS、Linux 分别发现该目录。测试不调用真实模型提供方，不操作用户应用。相关代码曾在 0.4.14 期间单独开发，后续发布证据见 [0.4.16 记录](../history/release-0.4.16.md)；不继续使用“工作区尚未发布”描述当前全部桌面能力。

test_launch_runtime.py 使用真实交互运行时、SQLite 持久化、VisualResource、动作校验与派发日志；模型响应、OS 调用、截图和稳定等待使用夹具。

| 场景 | 应满足行为 |
| --- | --- |
| 已连接浏览器休眠，模型响应期间桌面像素/焦点变化 | 清单应用仅启动一次，不截图无关浏览器；先保存意图，完成判断用启动后新图 |
| 点击前像素变化 | 输入派发前拒绝 |
| 输入前前台焦点变化 | 输入派发前拒绝 |
| 应用从清单消失 | 启动前拒绝 |
| 原生启动回执丢失 | needs_review；重复请求和重启恢复都不重放启动 |
| 模型调用期间暂停/停止 | 不启动、不提交新请求 |
| 模型明确请求浏览器 | 获取浏览器观察并在重启后保留资源选择 |
| 浏览器无法截图 | 不能判完成，转人工处理 |
| 非 UTF-8 系统的中文会话/接管说明 | 重载和连接列表保留文字，不丢弃会话 |

test_launch.py 验证启动前提和路由；test_connections.py 验证连接发现、桥安装顺序、应用清单、坐标和焦点；test_chat_ui.py/test_desktop.py/test_recovery.py 分别覆盖界面、模型配置及恢复。

这些确定性测试通过不能证明真实模型行为、应用实际启动成功、Chrome 安装或原生 macOS 输入；真实平台验收须独立留证。
