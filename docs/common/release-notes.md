# Saygo 0.4.19：人工接管键盘恢复与重复计算优化

本版修复 Android 人工接管后无法正常手动输入的问题，保留用户输入法和设备/任务
资源归属。还纳入 0.4.18 发布后的 QA 发现、截图计算、Runtime 历史读取重构，
以及网络采集清空后的在途正文计数修复。本轮发布范围为 PyPI Python 包。

## 主要修改

- Android 新连接不再永久启用 UnicodeIME，也不依赖现场驱动不支持的
  `resetKeyboard`。中英文自动输入仍通过 Appium `mobile: type` 临时使用
  UnicodeIME，输入前后保存并核验普通键盘。
- device、CLI/MCP、交互 task 和显式 workflow 共用接管准备。handoff 先暂停
  自动操作再恢复键盘；resume 保留用户的新选择并重新观察。恢复或截图失败
  保持暂停，输入结果不明时不重放，不重启应用、清数据或释放任务资源。
- 输入法记录随会话/任务保存。缺失历史选择时列出候选，由用户在系统设置中
  选择；重复接管与重连保留所有权。暂停期间显式重连仅在确认 Appium 会话
  失效时新建，网络失败不另建；新建后准备失败仍保存绑定供显式恢复。
- iOS 新连接保留 Simulator 当前软/硬键盘偏好，避免 XCUITest 默认值关闭
  电脑键盘；输入仍为聚焦元素 `send_keys`，不发送 Android IME 指令。
- QA 统一路径和目标归属解析，避免重复扫描；保留 feature 优先级与错误语义。
- 稳定帧和多帧采样复用图像；视觉差异用直方图统计，跳过零变化区域分析。
  原始截图、阈值、遮罩和采样结果不变，像素差不作为业务成功证据。
- Runtime 事件查询不再解析完整快照，导出复用一次历史读取；事件顺序、ZIP
  格式和待核对状态不变。增加可复跑基准及架构、操作和测试文档。
- 包内浏览器扩展源码修复清空采集后的 `pending_bodies`，迟到请求不再污染
  新采集计数；补充分页、缓存回退及错误路径测试和网络/隐私说明。

## 升级与迁移

QA、视觉、Runtime 参数、数据库结构与导出格式无需迁移。输入法记录为可选新增
状态；旧会话当前为 UnicodeIME 且缺少原选择时，需用户先在系统设置中选回
自己的普通键盘，再重试接管/恢复。不要假设升级或断开会自动找回历史选择。

暂停期间会话过期时，显式 connect 原设备、服务器和别名；重连仍保持暂停，
须用户交还控制后 resume 并使用新观察。iOS 旧会话若已改变模拟器键盘偏好且
没有历史值，需要用户在 Simulator 键盘菜单恢复；显式 caps 仍可覆盖默认设置。

PyPI 发布核实后可按原安装方式升级，例如 `pipx upgrade saygo-agent-control`，
随后重启 Agent 客户端。此次未直接升级用户安装的 0.4.18，也不修改其
site-packages、主动重载在线扩展或关闭 host。

扩展 manifest 仍为 0.4.17，本轮不上传商店、不创建 GitHub 公开 Release，
也不构建新桌面包。包内扩展源码更新不等于浏览器已加载修复，更不等于商店已
审核新版；安装版、浏览器实际加载代码与包发布须分别核实。

## 验证与限制

0.4.19 元数据更新后重跑核心离线检查：1,050 项，1,034 通过、16 跳过、0 失败。
独立 Windows Android API 35 模拟器与自有输入页已完成普通 CLI、真实 MCP
Runtime 的自动中英文输入、handoff、用户实际确认软/电脑键盘输入、resume
新截图及再次自动输入。旧 UnicodeIME 残留恢复、device/task 重复接管、暂停态
重连、页面内容与任务资源归属也已核验。

先前合成负载基准中，静态三帧采样约 156→70 ms，零变化视觉差异约
583→16 ms，事件读取约 9.7→4.3 ms；这不是本次重新测量或完整业务耗时。
环境、负载和完整数字见[性能记录](performance.md)。

真实过期会话重建、多普通键盘切换、故障注入和显式 workflow 接管仅有离线
覆盖；iOS 无本次真机/模拟器验收。本地 wheel/sdist 构建、严格元数据检查、
Linux 干净安装及重复 setup 已通过；CI 三平台安装、PyPI 可见性及下载哈希
尚待发布流程核实，不能用源码通过代替。状态和证据见
[0.4.19 发布验证](history/release-0.4.19.md)。
