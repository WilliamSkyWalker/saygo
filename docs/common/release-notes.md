# Saygo 0.4.21：延长观察有效期，选页保留窗口焦点

本版将 Python 包、native host、托管客户端插件和浏览器扩展统一升级为 0.4.21。
当前处于发布准备阶段；PyPI 可见、GitHub 附件上传、扩展商店提交及审核通过须分别核实。
发布范围为 Python 包、源码安装器和浏览器扩展，不构建新的原生桌面安装包。

## 行为变化

- **观察有效期从 30 秒延长至 60 秒。** 普通 device/CLI/MCP 动作和显式
  Runtime 工作流共用阈值，给外部 Agent 读图和决定下一动作留出更长时间。
  超过 60 秒仍拒绝派发；目标身份、画面及局部区域变化检查保持有效。
  这是观察保存后的年龄，不是截图调用的超时时间。
- **动作后截图直接用于操作记录。** `act` 启用 `observe_after` 并成功截图后，
  日志复用返回给调用者的同一张观察，不再为日志额外截图，避免返回前继续消耗
  这张观察的有效期。未请求动作后观察或该截图失败时，仍保留原有证据采集路径。
- **选页不再主动前置整个浏览器窗口。** `select-page`、`select_page` 动作和
  显式指定页面的连接仍切换目标窗口中的活动标签页，但不再请求窗口获得系统焦点。
  新建页继续在后台创建并保留原目标；截图与普通输入不增加前台回退。
- **浏览器重启记住连接选择。** 成功连接后，在同一浏览器配置文件下次启动时
  尝试恢复桥连接一次。Release 或 Chrome 调试器 Cancel 会关闭后续启动重连；
  首次安装、旧版没有保存偏好时仍需手动连接。扩展重载及 worker 唤醒不触发启动
  重连，失败不循环重试。弹窗显示下次启动的连接偏好及保存失败状态。
- **网络采集清空后的计数独立。** 清空时重置 `pending_bodies`，旧采集请求
  的迟到结果不再改动新采集计数。完整正文和缓存淘汰后的流恢复已经包含在
  0.4.17 扩展中，不作为本版新增能力。

仓库同时收录[个人 Agent 与任务知识库规划草案](../../PERSONAL_AGENT_PLAN.md)。
它是后续设计讨论，不代表本版实现了知识库、视觉动作复用或云端同步。

## 升级与已有会话

待确认 PyPI 0.4.21 可用后，按原安装方式升级 Python 包，并重启使用它的 Agent
客户端以加载新代码。若需更新托管插件副本，保留原客户端及 `--root` 等选项重新
执行 setup。无需清空会话、任务数据库或历史观察。

浏览器焦点、启动连接和网络计数修复位于扩展内；升级 Python 包不能替代浏览器
加载 0.4.21 扩展。商店提交不等于审核通过，审核通过也不等于用户当前配置已加载
新版。发布过程不主动重载用户扩展或结束在线 host；需要重连时由用户选择时机。
旧 page ID 在浏览器重启后仍须显式重新选择，启动重连不会恢复或重放业务输入。

原生桌面二进制不随本轮更新。源码或 Python 安装的桌面入口使用共用动作校验；
此前桌面包不会仅因 Python 包或扩展版本变化自动获得本次修改。

## 验证与发布边界

发布准备阶段的 Linux 离线核心检查共 1,060 项，1,042 通过、18 跳过；
扩展 Node 回归 77 项通过。新增回归覆盖 45 秒和恰好 60 秒可执行、超过 60 秒
不派发、有效期内画面变化仍拒绝、动作后观察与日志一致，以及选页不调用窗口聚焦。
这些结果不等于本版真实跨平台浏览器或业务操作验收。

新增的 headed Chromium 选页回归通过真实扩展、native host 和 CLI 验证其他窗口
保持前台，并在 Linux 检查实际活动窗口及堆叠顺序。本地缺少对应浏览器/窗口
管理器，尚未执行；发布 CI 将运行该检查、浏览器重启及现有截图/输入回归。
构建产物、三平台干净安装、重复 setup 和公开下载核验也仍待发布流程完成。

当前证据和后续状态记录于[0.4.21 发布验证](history/release-0.4.21.md)。
